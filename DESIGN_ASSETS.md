# Life Journal visual assets

## Direction

The product should feel like a quiet personal notebook that visibly collects small wins. Use an illustration as a reward or a gentle context cue, never as an obstacle to writing or checking off a habit.

## Sticker sheet

[`life-journal-sticker-sheet-v1.png`](public/assets/life-journal-sticker-sheet-v1.png) contains a transparent-background set for the first visual language:

| Meaning | Asset |
| --- | --- |
| Journal and reflection | Open notebook |
| A new habit | Sprout |
| Period progress | Grape cluster |
| One completed unit | Apple |
| Focus or practice | Piano key |
| Movement | Running shoe |
| Pause and care | Tea cup |
| Milestone | Star |
| Evening routine | Moon |
| Date and review | Calendar |
| Reminder | Mailbox |
| Gentle reset | Cloud |

## Use rules

- Show one sticker per section or milestone, at 32–72 px. The full sheet is a source asset and should not be shown in the app.
- Use the grape cluster for weekly or monthly completion moments, after the user reaches a meaningful fraction of their target.
- Use small CSS progress beads for live counts; reserve richer stickers for completion and review states.
- Keep the existing dark, quiet surface. Stickers supply the warm cream, sage, grape, and coral accents.
- Avoid repeated celebratory animation. A completed target may receive a single subtle scale or glow response.
